Pendahuluan

MateriApp ("kami", "aplikasi") adalah aplikasi kalkulator material bangunan yang membantu pengguna menghitung kebutuhan material konstruksi seperti bata, keramik, cat, beton, pondasi, atap, besi beton, dan plafon.

Kebijakan Privasi ini menjelaskan bagaimana kami menangani informasi saat Anda menggunakan aplikasi kami. Dengan menggunakan MateriApp, Anda menyetujui ketentuan yang dijelaskan dalam Kebijakan Privasi ini.

2

Informasi yang Kami Kumpulkan

2.1 Data yang Anda Masukkan (Lokal)

MateriApp menyimpan data berikut secara lokal di perangkat Anda:

  • Dimensi bangunan (panjang, lebar, tinggi)
  • Nama proyek dan daftar ruangan
  • Hasil perhitungan material semua kalkulator
  • Riwayat perhitungan
🔒 Data ini hanya tersimpan di perangkat Anda dan tidak dikirim ke server kami. Menghapus aplikasi akan menghapus semua data ini.

2.2 Data Backup Google Drive (Opsional)

Jika Anda mengaktifkan fitur Backup, data proyek akan disimpan di folder privat Google Drive milik Anda sendiri (appDataFolder). Data ini:

  • Hanya bisa diakses oleh MateriApp dan akun Google Anda
  • Tidak dapat dibaca oleh kami (developer)
  • Dapat dihapus kapan saja dari drive.google.com

2.3 Data yang Dikumpulkan Otomatis (Google AdMob)

Melalui layanan Google AdMob, data berikut dikumpulkan secara otomatis untuk keperluan penayangan iklan:

  • ID Iklan (Advertising ID / GAID)
  • ID Perangkat (Android ID sebagai fallback)
  • Informasi perangkat (jenis, OS, versi Android)
  • Data interaksi aplikasi (durasi sesi, fitur yang digunakan)
  • Alamat IP (untuk perkiraan lokasi pengguna)
⚠️ Data AdMob tidak dapat dinonaktifkan selama fitur iklan aktif. Untuk menonaktifkan personalisasi iklan: Pengaturan → Google → Iklan → Nonaktifkan Personalisasi Iklan
3

Penggunaan Informasi

Data digunakan untuk:

  • Menjalankan fitur kalkulator dan manajemen proyek
  • Menampilkan iklan yang relevan melalui Google AdMob
  • Backup dan restore data proyek via Google Drive (jika diaktifkan)
  • Menganalisis performa aplikasi secara anonim dan agregat

Kami TIDAK menggunakan data Anda untuk:

  • Menjual data kepada pihak ketiga
  • Mengidentifikasi Anda secara pribadi
  • Mengirimkan spam atau notifikasi yang tidak diminta
  • Tujuan komersial selain penayangan iklan
